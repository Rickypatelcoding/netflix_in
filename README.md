# Netflix Clone

A responsive Netflix clone website built with HTML, CSS, and JavaScript. This project replicates the core features and design of the Netflix streaming platform.

## Features

- Responsive design that works on various screen sizes
- Multi-language support (English, Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Marathi, Gujarati, Punjabi)
- Netflix-like UI with:
  - Hero section with call-to-action
  - Email signup form
  - Responsive navigation
  - Custom styling and animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Ubuntu and Martel Sans)

## Project Structure

- `index.html` - Main HTML structure
- `style.css` - Styling and animations
- `index.js` - JavaScript functionality
- Various assets (images, icons, logos)

## Setup

1. Clone the repository
2. Open `index.html` in your web browser
3. No additional dependencies required

## Note

This is a frontend clone project created for educational purposes. It does not include actual streaming functionality or backend services.
